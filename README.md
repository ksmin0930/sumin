# 한살림생산자연합회 자금현황 대시보드

웹주소로 함께 조회하고, 지정된 업로드 담당자만 기존 양식의 엑셀을 저장하는 Streamlit 대시보드입니다.

## 사용 방법

- 조회자: 웹주소에 접속해 저장된 기준월을 선택합니다.
- 업로드 담당자: 왼쪽의 `업로드 담당자 로그인`에서 비밀번호를 입력한 뒤 엑셀을 선택하고 `월별 자료 저장하기`를 누릅니다.
- 새 기준월은 자동 추가되고, 같은 기준월을 다시 저장하면 해당 월 자료가 최신 내용으로 교체됩니다.

## 데이터 보관

- 앱 코드는 이 공개 저장소에 있습니다.
- 월별 자료와 업로드 원본은 별도의 비공개 GitHub 저장소에만 보관합니다.
- 연결 정보와 업로드 비밀번호는 Streamlit Secrets에만 등록하며 코드에 포함하지 않습니다.

## 필요한 Streamlit Secrets

```toml
GITHUB_DATA_REPO = "ksmin0930/sumin-fund-data"
GITHUB_DATA_BRANCH = "main"
GITHUB_TOKEN = "GitHub fine-grained token"
UPLOAD_PASSWORD = "업로드 담당자 비밀번호"
```

## 필요한 엑셀 시트

- `02_월별요약_Looker`: 기준월과 상단 KPI 값
- `03_자금흐름_Looker`: 기준월, 흐름 항목, 금액
- `01_자금현황_입력`: 보통예금, 미수금, 용도제한자금 상세

시트명과 첫 번째 헤더 행은 기존 양식을 유지해 주세요.
